🔑 Cara Pakai API Key

  1. Minta API key ke admin, atau set sendiri via environment variable API_KEY di server.
  2. Sertakan key di setiap request terproteksi lewat header HTTP x-api-key.
  3. Key salah / tidak ada → server menjawab 401 dengan pesan "API key tidak valid".
curl -H 'x-api-key: KEY-KAMU' \
  -H 'Content-Type: application/json' \
  -X POST -d '{"text":"Halo!"}' \
  __BASE_URL__/api/ai

⚠️ Jaga API key seperti password — jangan taruh di kode frontend publik atau repo git.

⚖️ Rate Limit & Kode Error

  • 200 — Berhasil. Cek field status: true di body.
  • 400 — Parameter tidak valid / kurang. Pesan menjelaskan yang kurang.
  • 401 — API key tidak valid atau tidak disertakan (header x-api-key).
  • 404 — Endpoint tidak ditemukan.
  • 429 — Terlalu banyak request. Batas 60 request/menit per IP.
  • 502 — Layanan pihak ketiga (AI/TikTok/YouTube) gagal atau sibuk. Coba lagi nanti.
  • 503 — Fitur belum dikonfigurasi di server (mis. AI_API_URL kosong atau binary yt-dlp belum terpasang).

📌 Catatan: direct URL dari YouTube bersifat sementara dan bisa kedaluwarsa (biasanya dalam beberapa jam) — unduh segera setelah diterima.
